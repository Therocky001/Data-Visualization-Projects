## 📂 What's Inside

### ⚡ Power BI — `4-5 Dashboards`
Interactive dashboards built on demo and real-time datasets.  
Covers data cleaning, DAX formulas, slicers, and visual storytelling.

### 📈 Tableau — `3-4 Dashboards`
Visual analytics using Tableau's drag-and-drop interface.  
Includes charts, maps, filters, and calculated fields.

### 🔵 QlikView — `2 Dashboards`
Associative data model exploration using QlikView.  
Covers set analysis and dynamic dashboards.

### 🌐 Google Analytics — `1 Dashboard`
Web traffic and user behavior analysis using GA data.  
Covers sessions, bounce rate, acquisition channels.
